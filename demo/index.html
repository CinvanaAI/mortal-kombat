    Start with the installed command ↗main(argv) → load the task and reserve a new result directory
Validate and fingerprint the task ↗validate_task(raw) / fingerprint(task) → explicit task contract
Score the exact fields ↗assess_output(text, expected) → field matches or invalid JSON
Capture outputs and supply the judge ↗run_task(task) → evaluate(model, artifact) and judge(left, right)
Compare and insert into the ladder ↗run_tournament(...) → model A is candidate; model B is incumbent
    This page replays saved evidence; it does not call a provider or run Python in your browser. The source links show where validation, evaluation, and insertion happen.
    To supply your own task: mortal-kombat example my-task.json, then mortal-kombat run my-task.json to inspect the plan. Execution is explicit through --execute.
