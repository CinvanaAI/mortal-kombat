# From Mortal Kombat to Rubric Rumble

**Rubric Rumble** keeps the playful model-tournament idea and gives the project an identity of its own. Use `rubric-rumble` for the command line or `rubric-rumble gui` for the desktop.

The [repository](https://github.com/CinvanaAI/rubric-rumble) and [project website](https://cinvanaai.github.io/rubric-rumble/) use the new name. Old GitHub repository links redirect; old GitHub Pages bookmarks need the new website address.

## Compatibility

- The earlier `mortal-kombat` command remains an alias. The small `prompt-tournament-demo` command and `prompt_tournament` Python imports also remain available.
- The Python distribution is still `prompt-tournament-engine`; downloaded wheel filenames use `prompt_tournament_engine`.
- Saved task/result schema identifiers keep their earlier names and formats. There is no need to rename fields inside saved evidence.

Original battle records, timestamps, model IDs and captured text are preserved. The historical flow describes the original evaluator; the current [operating atlas](https://cinvanaai.github.io/rubric-rumble/operations/) describes the standalone application.
