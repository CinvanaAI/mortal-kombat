# From Mortal Kombat to Rubric Rumble

The project now uses **Rubric Rumble** as its public name. It keeps the playful model-tournament idea and gives the project an identity of its own.

## Names you may see

| Name | Meaning |
| --- | --- |
| Rubric Rumble / `rubric-rumble` | Current project name, repository and preferred command |
| `prompt-tournament-engine` | Python distribution; the downloaded wheel filename uses `prompt_tournament_engine` |
| `prompt_tournament` | Python import used by existing library callers |
| `mortal-kombat` | Earlier command, retained as a compatibility alias |
| `mortal-kombat.*.v1` | Existing task/result/evidence schema identifiers; saved files keep their formats |

## Existing users

- Install or update from `https://github.com/CinvanaAI/rubric-rumble`.
- Use `rubric-rumble` for the command-line application and `rubric-rumble gui` for the desktop.
- The earlier `mortal-kombat` command remains a compatibility alias. `prompt-tournament-demo`, the `prompt-tournament-engine` Python distribution and `prompt_tournament` imports remain available.
- Existing task and result schema identifiers remain unchanged, so saved files continue to load. An old name inside a schema or historical record is intentional.
- Existing GitHub repository links redirect. Update local remotes to `https://github.com/CinvanaAI/rubric-rumble.git` when convenient.
- The project website is now `https://cinvanaai.github.io/rubric-rumble/`. GitHub Pages does not provide the same repository-rename redirect; update old website bookmarks.

Original battle records, timestamps, model IDs and captured text are preserved. The historical flow describes the original evaluator; the current [operating atlas](https://cinvanaai.github.io/rubric-rumble/operations/) describes the standalone application.
